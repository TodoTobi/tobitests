# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Please report them via GitHub's private vulnerability reporting:
👉 [Security Advisories](https://github.com/TodoTobi/tobitests/security/advisories/new)

Or email: **security@todotobi.dev**

You can expect an acknowledgement within **72 hours** and a resolution timeline within **14 days** for confirmed issues.
